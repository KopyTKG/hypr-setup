# omarchy-config

Personal Omarchy (Hyprland) configuration, captured from a working install of
[Omarchy](https://omarchy.org/) **3.7.1** as a starting point to build on.

## Layout

The `config/` tree mirrors `~/.config/`. Drop a file in here and the install
script symlinks it into `~/.config/<same-relative-path>`.

```
config/
├── hypr/                # Hyprland: bindings, monitors, animations, idle, lock
├── waybar/              # Status bar layout + style
├── walker/              # App launcher
├── alacritty/ kitty/ ghostty/   # Terminals
├── mako/                # Notification daemon
├── swayosd/             # OSD overlays
├── omarchy/             # Hooks, custom themes, branding
│   ├── hooks/           # theme-set / font-set / post-update / battery-low
│   ├── themes/          # Custom themes (drop a dir here)
│   └── branding/        # about.txt, screensaver.txt
├── btop/ fastfetch/ lazygit/ tmux/ git/   # CLI tools
├── starship.toml        # Prompt
├── elephant/ fcitx5/ fontconfig/ environment.d/ systemd/ uwsm/
├── chromium/ obsidian/ Typora/ xournalpp/ opencode/   # App configs (only Omarchy-tracked files)
├── brave-flags.conf chromium-flags.conf   # Browser GPU/Wayland flags
├── omarchy.ttf          # Icon font used by waybar
└── xdg-terminals.list   # Default terminal preference
```

## Scope: what's included, what isn't

Files in this repo come from two sources:

1. **Path-mirror** — every file Omarchy upstream ships under
   `~/.local/share/omarchy/config/` is mirrored from this user's
   `~/.config/`. This is the precise "Omarchy distro tweak surface".
2. **Customization hubs** — wholesale-copied: `omarchy/`, `mako/`, `hypr/`,
   `waybar/`, `walker/`, `alacritty/`, `kitty/`, `ghostty/`, `swayosd/`. These
   are where extra user tweaks tend to land beyond what upstream tracks.

**Excluded:**

- `config/omarchy/current/` — runtime theme state, regenerated by
  `omarchy theme set`
- `*.bak.*` files — `omarchy refresh` backups
- Browser profiles, extension data, caches (e.g. full `~/.config/chromium/`
  beyond the single `Default/Preferences` Omarchy tracks)
- System-level Omarchy defaults that live outside `~/.config/`
  (`/etc`, `~/.bashrc`, sddm, plymouth, udev, snapper, wireplumber, etc.) —
  these are deployed by Omarchy's installer; see
  `~/.local/share/omarchy/default/` if you want to fork them.

## Install

```bash
./install.sh           # symlinks config/* into ~/.config/
./install.sh --copy    # copies instead of symlinking (safer for one-offs)
./install.sh --dry-run # show what would happen, change nothing
```

Existing files are backed up with a timestamp suffix before being replaced.

After install, restart components that don't auto-reload:

```bash
hyprctl reload && hyprctl configerrors
omarchy restart waybar
omarchy restart walker
omarchy restart terminal
```

## Useful Omarchy commands

```bash
omarchy commands              # All available commands
omarchy refresh <app>         # Reset an app's config to upstream defaults
omarchy restart <app>         # Restart a component
omarchy theme set <name>      # Apply a theme
omarchy theme list            # Show available themes
omarchy debug --no-sudo --print   # Diagnostic dump
```

## Build on top

- New keybindings → `config/hypr/bindings.conf` (use `unbind` first if
  overriding an existing binding)
- New theme → `config/omarchy/themes/<name>/` (use stock themes in
  `~/.local/share/omarchy/themes/` as reference)
- Automation → drop a script in `config/omarchy/hooks/` (without the `.sample`
  suffix). Available hooks: `theme-set`, `font-set`, `post-update`,
  `battery-low`.
- Window rules → `config/hypr/hyprland.conf`. **Verify current syntax** at
  https://github.com/hyprwm/hyprland-wiki/blob/main/content/Configuring/Window-Rules.md
  before writing rules; the syntax changes between Hyprland versions.
