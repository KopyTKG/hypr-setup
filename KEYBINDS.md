# Keybinds

Every keybind in this setup, generated by `arch-keybinds --md` (the same data SUPER+F1 shows, where you can type to filter). Hyprland binds come from the live session, the waybar clicks from `waybar/modules.jsonc`, the keys of installed apps (fish, kitty, yazi, mpv, nvim) from the apps themselves, and the rest from [`arch-menu/keybinds.conf`](arch-menu/keybinds.conf) — edit that file for keys that cannot be read from an app, then regenerate:

```sh
arch-keybinds --md > ~/Projects/hypr-setup/KEYBINDS.md
```

> **⚠ Shared key combinations.** Two binds are registered for each of these, so one key press can trigger both: `SUPER + C` (Universal copy / Calendar); `SUPER + CTRL + I` (Toggle locking on idle / Messenger).
