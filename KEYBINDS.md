# Keybinds

Every keybind in this setup, generated by `arch-keybinds --md` (the same data SUPER+F1 shows, where you can type to filter). Hyprland binds come from the live session, the waybar clicks from `waybar/modules.jsonc`, and everything else from [`arch-menu/keybinds.conf`](arch-menu/keybinds.conf) — edit that file for the non-Hyprland keys, then regenerate:

```sh
arch-keybinds --md > ~/Projects/hypr-setup/KEYBINDS.md
```

> **⚠ Shared key combinations.** Two binds are registered for each of these, so one key press can trigger both: `SUPER + C` (Universal copy / Calendar); `SUPER + CTRL + I` (Toggle locking on idle / Messenger).

|------|--------------|

| `ENTER` | Pick the highlighted row or tile / submit the form |

| `UP / DOWN` | Move through a list |
| `PAGE UP / DOWN` | Move ten rows in a list |

| `SPACE` | Toggle a row in a multi-select list (SHIFT / CTRL + arrows select ranges) |
| `TAB` | Move between the fields of a form |
| `CTRL + ENTER` | Submit from a multi-line text box (plain Enter is a newline) |
| `BACKSPACE` | Back, on tiles, a list or an empty search (only when the dialog has a Back button) |
| `ALT + LEFT` | Back, from anywhere in the dialog (only when it has a Back button) |
